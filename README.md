# FTCLibrariesList
A list of as many FTC libraries to help programmers and maintainers!

## Goals
* A list of as many FTC libraries, with their name, description and link to installation in an organized manner
* Help maintainers of those libraries get the attention they need
* Help FTC programmers find amazing libraries get the attention they need

## How to help
* Create a pull request and add more FTC libraries
* **Star this repository!**
* **Share this repository with others!**
---

## Libraries
### Collection of libraries
* [Dairy](https://docs.dairy.foundation/introduction)
  * Ecosystem of open source FTC libraries
* [NextFTC](https://nextftc.dev/)
  * [NextFTC](https://nextftc.dev/nextftc/)
    * Command-based framework
  * [NextControl](https://nextftc.dev/control/)
    * Robust control library
  * [NextBindings](https://nextftc.dev/bindings/)
    * Gamepad binding library
  * [Extension - Pedro Pathing](https://nextftc.dev/extensions/pedro/)
    * NextFTC integration with Pedro Pathing
  * [Extension - Road Runner](https://nextftc.dev/extensions/roadrunner/)
    * NextFTC integration with Road Runner
  * [Extension - FateWeaver](https://nextftc.dev/extensions/roadrunner/)
    * NextFTC integration with the FateWeaver Library
* [SolversLib](https://docs.seattlesolvers.com/)
  * Fork of FTCLib, goal is to improve the initial programming experience for new members as well as greatly enhance the efficiency of code for veterans
### Hot Cold Reload
* [Sloth](https://github.com/Dairy-Foundation/Sloth?tab=readme-ov-file)
  * Fastest hot code reload library for FTC
### Logging
* [FateWeaver](https://github.com/HermesFTC/FateWeaver/)
  * A Road Runner log based data logging library for FTC robotics
### Pathfinding and motion planning
* [Hermes](https://hermes.zharel.gay/)
  * A revolutionary motion profiling and planning algorithm that builds on RoadRunner
* [Pedro Pathing](https://pedropathing.com)
  * A path follower designed to revolutionize autonomous pathing in robotics
* [Road Runner](https://rr.brott.dev/docs/)
  * Wheeled mobile robot motion planning library designed for FTC
### Vision
* [EasyOpenCV](https://github.com/OpenFTC/EasyOpenCV)
  * A straightforward and easy way to use OpenCV on an FTC robot
