## About

This repository serves as a place to discover new FTC resources. Whether you're:
-  A rookie team with no experience
-  Looking to optimize your code
-  Maintaining an FTC library

... you will find resources organized by category to help you find exactly what you need.

### Our Goals
✅ Organize all major FTC libraries in one accessible location  
✅ Allow library maintainers to reach more developers  
✅ Accelerate FTC programmers' ability to find and implement quality tools

## Libraries

### 🏗️ Command Frameworks & Ecosystems
*Frameworks for structuring FTC robot code*

- **[Dairy](https://docs.dairy.foundation/introduction)** - Ecosystem of open source FTC libraries
- **[NextFTC](https://nextftc.dev/)** - Command-based framework with integrated tools
  - [NextFTC](https://nextftc.dev/nextftc/) - Core framework
  - [NextControl](https://nextftc.dev/control/) - Robust control library
  - [NextBindings](https://nextftc.dev/bindings/) - Gamepad binding library
  - [Extension - Pedro Pathing](https://nextftc.dev/extensions/pedro/) - Pedro Pathing integration
  - [Extension - Road Runner](https://nextftc.dev/extensions/roadrunner/) - Road Runner integration
  - [Extension - FateWeaver](https://nextftc.dev/extensions/fateweaver/) - FateWeaver integration
- **[FTCLib](https://ftclib.org/)** - Comprehensive command-based structure and utilities
- **[SolversLib](https://docs.seattlesolvers.com/)** - Enhanced FTCLib fork with focus on onboarding and performance
- **[BunyipsLib](https://github.com/Murray-Bridge-Bunyips/BunyipsLib)** - General-purpose library with utilities and abstractions
- **[FtcTemplate (TrcLib)](https://github.com/trc492/FtcTemplate)** - Template-based framework from Titan Robotics Club
- **[Mercurial](https://github.com/Dairy-Foundation/Mercurial)** - Modular library by Dairy Foundation

### 🔄 Hot/Cold Reload
*Reload code without restarting your robot*

- **[Sloth](https://github.com/Dairy-Foundation/Sloth?tab=readme-ov-file)** - Fastest hot code reload library for FTC

### 📊 Logging & Telemetry
*Monitor and log robot performance (includes dashboards)*

- **[FateWeaver](https://github.com/HermesFTC/FateWeaver/)** - Road Runner-based data logging library for FTC robotics
- **[PsiKit](https://psilynx.github.io/PsiKit/)** - Advanced toolkit for vision and automation features
- **[FTC Dashboard](https://acmerobotics.github.io/ftc-dashboard/)** - Real-time dashboard for monitoring and debugging

### 🛣️ Autonomous Movement
*Path planning and trajectory tracking*

- **[Hermes](https://hermes.zharel.gay/)** - Revolutionary motion profiling and planning algorithm built on Road Runner
- **[Pedro Pathing](https://pedropathing.com)** - Advanced path follower for autonomous navigation
- **[Road Runner](https://rr.brott.dev/docs/)** - Industry-standard motion planning library for FTC
- **[MeepMeep](https://learnroadrunner.com/tool/meepmeep)** - Road Runner trajectory simulator and visualizer

### 👁️ Vision & Detection
*Computer vision and image processing for FTC*

- **[EasyOpenCV](https://github.com/OpenFTC/EasyOpenCV)** - Streamlined OpenCV integration for FTC
- **[EOCV-Sim](https://github.com/deltacv/EOCV-Sim)** - OpenCV pipeline simulator for testing without a robot
